# Biblioteca Triple Peaks
 
A responsive landing page for the Triple Peaks Library, a TriplrTen project of a fictional library aimed at developers and students looking for a place to study, grow, and connect.
 
## Problem it Solves
 
Local libraries often lack a modern, welcoming online presence. This landing page gives the Triple Peaks Library a clean digital home where visitors can discover staff book picks, upcoming events, and how to become a member.
 
## Technologies Used

- **HTML5** — Semantic page structure
- **CSS3** — Styling and visual presentation
- **Flexbox / CSS Grid** — Responsive layout across sections
- **BEM Methodology** — Scalable and maintainable CSS class naming
